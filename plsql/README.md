# Oracle PL/SQL Learning

This folder tracks practical Oracle PL/SQL learning for university coursework.

## Environment
- Database: Oracle Database 11g Express Edition (XE)
- Runner: SQLcl from VS Code (`Run in SQLcl`)
- Output: `SET SERVEROUTPUT ON;` + `DBMS_OUTPUT.PUT_LINE`
- Run PL/SQL blocks in SQLcl with `/` on a new line after `END;`

## Structure
- `notes/` — lesson notes
- `practice/` — runnable examples
- `exercises/` — exercises to solve independently

## Learning rules
1. Try each exercise before checking a solution.
2. Keep Oracle PL/SQL syntax separate from MySQL syntax.
3. Record errors and their fixes.
