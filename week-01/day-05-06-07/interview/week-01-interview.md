# SQL Interview Practice — Week 1

Answer aloud before checking each sample.

## Q1. INNER JOIN vs LEFT JOIN
“INNER JOIN returns only rows that have matching records in both tables. LEFT JOIN returns all rows from the left table, including rows without a match in the right table.”

## Q2. WHERE vs HAVING
“WHERE filters rows before grouping, while HAVING filters groups after grouping.”

## Q3. COUNT(*) vs COUNT(column_name)
“COUNT(*) counts all rows. COUNT(column_name) counts only non-NULL values in that column.”

## Q4. Primary Key vs Foreign Key
“A primary key uniquely identifies each row in a table. A foreign key links tables by referencing a key in another table.”

## Q5. DELETE vs TRUNCATE vs DROP
“DELETE removes rows and can use WHERE. TRUNCATE removes all rows but keeps the table structure. DROP removes the table structure and its data.”
