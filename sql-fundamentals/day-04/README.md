# Day 4 — Aggregate Functions, GROUP BY & HAVING

## Goals
- Use `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`.
- Understand how `NULL` affects aggregate functions.
- Group rows with `GROUP BY`.
- Filter rows with `WHERE` and groups with `HAVING`.
- Combine filtering, grouping, and sorting.

## Files
- `notes.md`: concepts and examples.
- `practice.sql`: practice queries for the `students` table.

## Before running
These queries assume a table named `students` with columns such as `age` and optionally `phone`.
Check your schema with `DESCRIBE students;`. Adjust queries if your table or column names differ.
